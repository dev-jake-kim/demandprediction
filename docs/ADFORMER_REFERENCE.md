## 4. 비교 시 주의

- **test 샘플 수가 다르다.** ADFormer는 Ulsan 652(24h)·654(8h), Porto 1,310(24h)·1,313(8h)이고
  이 저장소 모델은 입력 창과 무관하게 Ulsan 656, Porto 1,314다. 같은 시점 집합에서 잰 값이
  아니므로 수치 비교는 보고값 간 비교다.
- **MAPE 분모 정의가 기록돼 있지 않다.** 이 저장소의 MAPE(+1)와의 비교는 보고값 간 비교로만
  해석한다.
- 평균 학습 시간(시드당): Ulsan 996초(24h) → 348초(8h), Porto 3,383초(24h) → 1,090초(8h).
